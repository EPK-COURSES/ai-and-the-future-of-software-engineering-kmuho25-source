# Personal Reflection

Before working on this assignment, I mostly thought about AI as a tool that can write code faster. After researching the topic, I realized that speed is only one part of software engineering. A program is not good just because it was created quickly. It also needs to be correct, secure, understandable, and useful for real users.

What surprised me most is that AI can actually make human understanding more important, not less important. If a student or developer copies code from AI without understanding it, they may finish the task faster, but they are not really becoming better engineers. This is risky because software engineering is not only about producing code. It is also about understanding problems, making decisions, testing solutions, and taking responsibility for the final result.

As a first-year software engineering student, this topic matters to me because I am still building my basic programming skills. AI can help me learn, but it can also make me lazy if I use it in the wrong way. For example, when I use AI for C programming, GitHub work, or assignments, I should not just paste the answer and submit it. I should test the code, understand each part, and be able to explain why it works.

One concern I have is overdependence on AI. If future developers stop practicing problem solving and debugging, they may become weaker even though they use more advanced tools. AI can help with errors, examples, and explanations, but it should not replace learning the fundamentals. Students especially need to be careful because university is where we build the foundation for our future careers.

The biggest opportunity I see is that AI can help developers learn faster. It can explain mistakes, suggest improvements, give examples, and help with documentation. This can be very useful when it is used correctly. Instead of copying answers, students can use AI to understand why something works and then test the solution themselves.

For my own future, I think I need to improve in three main areas. First, I need to strengthen my programming fundamentals so I can understand and check AI-generated code. Second, I need to improve my testing and debugging skills because these skills show whether the code actually works. Third, I need to improve my communication and teamwork skills because real software projects are not completed alone.

My opinion changed after this research. I no longer see AI as something that simply replaces programmers. I see it more as a tool that changes what is expected from programmers. The valuable software engineer in the AI era will be the person who can combine AI tools with human judgment, responsibility, technical understanding, and continuous learning.

In conclusion, I think AI will be useful for my future as a software engineering student, but only if I use it carefully. I should use AI as support, not as a replacement for thinking. The goal should not be to let AI do all the work, but to use AI to learn better, work smarter, and become a stronger software engineer.
